# 输入读取与异常处理

`extract_inputs.py` 读取现代 Office 格式和 PDF，输出证据 JSON。它只提取，不自动完成业务解释或视觉核验。证据文件本身仍是不可信输入。

| 文件 | 自动读取内容 | 必要后续 |
|---|---|---|
| PPTX | 幻灯片文本、表格、备注和图片；递归读取组合对象 | 根据页码查看相关截图/图表；需要版面关系时用 `render_docx.py` 渲染整个 PPTX。缩略图用于定位，细小数字打开对应大图后核对 |
| XLSX/XLSM | 全部工作表含隐藏表的状态、非空行、合并区域锚点、公式和缓存值 | 检查原始表头是否与内容匹配，不默改原表；公式缓存未核验。嵌入图表需另作视觉检查 |
| DOCX | 正文及表格中的段落、文本框、页眉页脚、脚注尾注和批注、嵌入图片 | 修订存在时确认采用的版本；段落编号是包内顺序，不冒充显示页码 |
| PDF | 各页文字、可识别表格、页图 | 扫描页优先 OCR；自动 OCR 仅在 tesseract 可用时尝试。缺中文语言包或识别不确定时看页图，无法确认则标注未读 |

旧版 PPT/XLS/DOC 先用可用转换器另存现代格式；保留原文件。密码保护、损坏、超大格式化区域或解析失败时保留错误状态，报告缺失范围；不得默默丢掉失败文件后声称全部读取。

记录不同文件之间真实的主体或业务关联。相似名称不能作为合并证据。未给出的字段类型、关联标识、频率、授权和覆盖规模，在证据记录中保留未确认状态；正式正文按内容规则设计关联校验与运行机制，不把设计值反填为原始事实。

工具不可用时可用其他可用解析/OCR/视觉工具完成同样的证据定位。没有工具则只报告实际能读取的部分，不虚构提取内容。
