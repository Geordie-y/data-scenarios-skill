# 样例样式与槽位契约

原始参考保留在 `assets/reference.docx`。机器证据及各包内容 SHA-256 见 `style-evidence.json`。以参考文件为准；不要施加通用商务文档预设。

## 页面与文字

- 单节、A4 纵向：11906 × 16838 twips；上下边距 1440 twips（2.54 cm）；左右 1797 twips（约 3.17 cm）。一栏。
- 页眉距离 737、页脚距离 992 twips；样例无可见页眉、页码，第一页页脚为空。保留原关系和设置，不另加页码。
- 正文样式 ID `1`：仿宋_GB2312、16 pt，西文 Times New Roman；两端对齐，首行缩进 2 字符，固定行距 28 pt，段前后 0。
- 行业标题 ID `2`：黑体 16 pt；左对齐，单倍行距，段前后各 13 pt，keepNext/keepLines；编号“（一）”。
- 场景名称 ID `3`：楷体_GB2312 16 pt；左对齐，继承正文固定行距，段前后各 6 pt；编号“1.1”。
- 七节标题 ID `4`：16 pt、加粗，东亚字体继承主题 majorEastAsia，其 Hans 字体为宋体；左对齐，段前后各 3 pt；编号“1.1.1”。不擅自用黑体替换主题字体。
- 原编号 `numId=1`、`abstractNumId=0`，三级分别 chineseCountingThousand / decimal / decimal。按行业、场景、七节自然续排与重启，不将数字写入标题字符串。
- 案例正文复用普通正文；一览表案例列保留参考红色强调。正式材料无真实案例时填写应用示例。

## 表格

唯一结构为两行五列的场景一览表。总宽 8309 twips，各列 1080 / 3324 / 1413 / 1246 / 1246。固定布局、无底纹，内外边框 single 0.5 pt，单元格左右内距 108 twips，上下 0，垂直居中。表头与正文使用参考原段落和 run 格式。

表头黑体 9 pt，居中、单倍行距，无首行缩进；表体仿宋_GB2312 9 pt，案例列 C00000 红色并加粗。表体段落设置直接保留源 XML，不重新建立近似样式。内容自适应行高，不通过拉宽列或压小字改变版式。

## 槽位

`word/document.xml` 的 body 前两段分别为行业、场景标题。随后七个固定三级标题不改名。每个标题后的正文可按需重复原正文段落；场景一览表的第二行替换五个单元格内容。多场景克隆相同组件，多行业克隆行业标题。字数变化允许自然增页，不固定页数。

模板将业务内容替换为 `{{industry}}`、`{{scene_name}}`、`{{section_1}}` 等槽位；它是生成器资源，不是交付用户的成品。正式材料必须无槽位残留。

## 包保真与验证

只编辑 `word/document.xml`。其他包内容包括 styles、numbering、theme、fontTable、settings、customXml、页脚、脚注、尾注和关系均保持字节不变；参考文件保留不变。`check_docx.py` 验证不可编辑部分与模板一致，以及页面和表格结构。

参考在本机修正字体配置后渲染为 2 页。原字体不全部可用：预览采用仿宋-简 FangS-SC、汉仪楷体简 HYKaiTiJ、黑体/宋体的系统替代。原 DOCX 字体声明不变。`render_docx.py` 记录 PDF 实际字体；跨电脑的字体替代可能改变字形与分页，不能声称像素级一致。

每次检查所有最终页：无中文缺字、文字裁切、表格越界，标题不孤悬，页尾不留大量可避免空白。优先精简冗余段落并使用自然分页，不能删固定章节或缩小样例字号。证据缺失记录在独立编制说明，不插入正式正文。
